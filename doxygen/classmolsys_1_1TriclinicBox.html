◆ wrapPositionIntoBox()

linalg::Vec3D molsys::TriclinicBox::wrapPositionIntoBox ( const linalg::Vec3D & pos) const
nodiscardoverridevirtual

wraps atoms into the primary triclinic box unit cell

Parameters
posposition to be wrapped

This function images atoms back into the triclinic box with fractional coordinates in the range [-0.5, 0.5). This centers the box at the origin and is useful for output visualization where you want all atoms within the primary unit cell rather than the nearest image to the origin.

Returns
linalg::Vec3D wrapped position with box centered at origin
