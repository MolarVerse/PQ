Detailed Description

Benchmarks

The Google Benchmark suite measures core kernels and algorithms with statistical wall-clock sampling. It is separate from the fixed-work callgrind benchmarks in benchmarks/perf.

Configure and build a release suite:

cmake -S . -B build-benchmark \
-DCMAKE_BUILD_TYPE=Release \
-DBUILD_WITH_BENCHMARKING=On \
-DBUILD_WITH_TESTS=Off \
-DBUILD_WITH_ASE=Off
cmake --build build-benchmark --target google_benchmarks

Run the short smoke set:

ctest --test-dir build-benchmark -L benchmark --output-on-failure

Run the full local suite from the repository root:

./benchmarks/run_benchmarks.sh build-benchmark

The runner measures every registered case for at least three seconds and writes one JSON result per executable to benchmark-results. Set PQ_BENCHMARK_MIN_TIME to adjust the sampling time.

The benchmarks are standalone executables under build-benchmark/benchmarks/src; they are not invoked through the pq executable. Google Benchmark options such as --benchmark_filter and --benchmark_out can narrow or save the results:

./build-benchmark/benchmarks/src/benchmark_forceCalculation
