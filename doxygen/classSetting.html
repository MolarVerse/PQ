Detailed Description

template<typename T, mstd::Tag Name = mstd::Tag("Settings")>
class Setting< T, Name >

A template class representing a configurable setting.

Template Parameters
TThe type of the setting value.
TagThe tag type providing a name for the setting. This should be an instance of mstd::Tag with a unique string identifier. The tag is used to generate meaningful error messages when the setting is not set and no default is available.
