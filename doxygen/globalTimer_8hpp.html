Scoped timer for a specific section of code.

This function creates a scoped timer for a specific section of code. It starts the timer when the function is called and stops it when the returned TimingsSectionGuard object goes out of scope.

Parameters
idThe TimerId for the section of code being timed.
sectionNameA descriptive name for the section of code being timed.
Returns
A TimingsSectionGuard object that manages the timing of the specified section of code.
