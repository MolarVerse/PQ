void QM::QMRunner::throwAfterTimeout ( const std::stop_token & stopToken,
const TimeMs & qmLoopTimeLimit )
static

function to throw an exception after a timeout

This function is used to throw an exception after a timeout. The timeout is set in the settings file. If the timeout is set to 0, the function will return without throwing an exception.

Parameters
stopTokenThe stop token used to check for cancellation of the QM calculation loop
qmLoopTimeLimitThe maximum allowed time for the QM calculation loop. If the loop exceeds this time, an exception will be thrown. A value of 0 indicates no time limit.
Exceptions
QMRunnerExceptionif the timeout is exceeded
