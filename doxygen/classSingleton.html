Detailed Description

template<typename T>
class Singleton< T >

Singleton class template.

This header file defines a Singleton class template that provides a thread-safe implementation of the Singleton design pattern. It ensures that only one instance of the specified type T is created and provides global access to that instance.

Template Parameters
TThe type of the singleton instance.
