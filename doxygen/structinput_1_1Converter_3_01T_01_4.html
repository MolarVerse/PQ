Detailed Description

template<std::signed_integral T>
requires (!std::same_as<T, bool>)
struct input::Converter< T >

Converter specialization for plain integral types (size_t, int, unsigned, ...), excluding bool.

Converter specialization for enums generated by MSTD_ENUM / MSTD_ENUM_BITFLAG.

covers keys with no natural enum/double/bool representation (e.g. counts, indices) without requiring a per-key customParser for the common case

Template Parameters
T

these enums already carry their own name<->value table via mstd::enum_meta_t<T> – no separately maintained map is needed here. Per-key aliases or spellings the generated from_string can't express go through InputKey's customParser instead.
