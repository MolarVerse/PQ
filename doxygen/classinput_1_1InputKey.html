Detailed Description

template<typename T>
class input::InputKey< T >

owns key identity, default/actual value storage, and the allowed-values restriction for a single input-file key

delegates raw-token -> T conversion entirely to Converter<T> (or a per-key customParser override) – no parsing logic lives here
