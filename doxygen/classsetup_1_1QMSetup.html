◆ setupQMScript()

void setup::QMSetup::setupQMScript ( ) const

checks if a singularity or static build is used and sets the qm_script accordingly

if a singularity or static build is used the qm_script is set to the qm_script_full_path and the script path is set to the empty string to avoid errors. This is necessary because the script can not be accessed from inside the container. Therefore the user has to provide the script somewhere else and give the full or relative path to it. For more information please refer to the documentation.
