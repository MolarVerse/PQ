TEST_F ( TestPhysicalData ,
defaultConstructedIsZero  )

a default initialised PhysicalData has no garbage in it

Vec3D and tensor3D do not initialise their components. The PhysicalData that holds the averages is a member of the engine and default initialised (PhysicalData data;, unlike PhysicalData(), which zeroes the whole object first), so the first energy and momentum line of a run showed whatever the memory held, now and then inf, which failed the regression test of the smoke run. The storage is filled with 0xFF (a NaN as a double) before the object is built into it.
