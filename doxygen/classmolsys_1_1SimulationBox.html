Detailed Description

contains all particles and the simulation box

The SimulationBox class contains all particles and the simulation box. The atoms positions, velocities and forces are stored in the SimulationBox class. Additional molecular information is also stored in the SimulationBox class.

◆ removeNetForce()

void molsys::SimulationBox::removeNetForce ( )

Remove net force from the QM atoms.

Computes the total force on the QM atoms, distributes the opposite mean force equally to the QM atoms, and thereby enforces zero total QM force. MM atoms are not touched.

make external to internal global vdw types map

the function consists of multiple steps: 1) fill the external global vdw types vector with all external global vdw types from all molecules 2) sort and erase duplicates 3) fill the external to internal global vdw types map - internal vdw types are defined via increasing indices 4) set the internal global vdw types for all molecules
