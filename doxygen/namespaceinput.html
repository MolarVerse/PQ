InputFileParser::ParseFunc input::adapt ( const DeprecatedInputKey & deprecatedKey)
nodiscard

Adapts a DeprecatedInputKey into an InputFileParser::ParseFunc.

Provides integration between the DeprecatedInputKey and the existing InputFileParser::ParseFunc callback mechanism, allowing DeprecatedInputKey::parse to be registered with InputFileParser::addKeyword without modifying InputFileParser or InputFileReader.

Creates a callback that forwards InputFileParser::ParseFunc calls to the corresponding DeprecatedInputKey::parse method. Both signatures accept (const std::vector<std::string>&, size_t lineNumber) and are structurally identical, making this a simple forwarding wrapper.

Parameters
deprecatedKeyThe DeprecatedInputKey instance to adapt. Copied into the returned callable, since callers typically construct it as a local temporary that would otherwise not outlive the registration.
Returns
InputFileParser::ParseFunc that delegates parse requests to a copy of deprecatedKey and forwards (lineElements, lineNumber) arguments to deprecatedKey.parse().

◆ adapt() [2/2]

InputFileParser::ParseFunc input::adapt ( InputKeyBase & key)
nodiscard

Adapts an InputKeyBase into an InputFileParser::ParseFunc.

Provides integration between the InputKey<T>/InputRegistry design and the existing InputFileParser::ParseFunc callback mechanism, allowing InputKeyBase::parse (type-erased key handler) to be registered with InputFileParser::addKeyword without modifying InputFileParser or InputFileReader.

Creates a callback that forwards InputFileParser::ParseFunc calls to the corresponding InputKeyBase::parse method. Both signatures accept (const std::vector<std::string>&, size_t lineNumber) and are structurally identical, making this a simple forwarding wrapper.

Parameters
keyThe InputKeyBase instance to adapt. Typically obtained from an InputKey<T> that has been type-erased. Must remain valid for every invocation of the returned ParseFunc. The registry owning key is expected to outlive the InputFileParser instance that registers the adapted callback.
Returns
InputFileParser::ParseFunc that delegates parse requests to key. The returned callable captures a reference to key and forwards (lineElements, lineNumber) arguments to key.parse().
Note
Implemented as a capturing lambda rather than std::bind_front to avoid libc++ _Callable trait incompatibility issues encountered elsewhere in the parser infrastructure.
