Detailed Description

template<Color::Code colorCode = Color::Code::FG_RED, ExceptionType exceptionType = ExceptionType::Undefined>
class exc::BaseException< colorCode, exceptionType >

Base class for custom exceptions.

This class serves as a base for all custom exceptions in the application. It provides common functionality such as message handling, line number tracking, and colorful output for exception messages.

Template Parameters
ColorThe color code for the exception message output
TypeThe type of exception being thrown
