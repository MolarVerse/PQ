processes one line of the improper dihedral section of the parameter file and adds the improper dihedral type to the force field

The line is expected to have the following format:

  1. dihedralTypeId
  2. forceConstant
  3. periodicity
  4. phaseShift
Note
for the improper dihedral a general ff::DihedralType is used
