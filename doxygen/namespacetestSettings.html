Detailed Description

Helpers to construct settings objects in tests without the input file parser and without the static settings facade.

Every settings struct is default-constructible, so a test builds the one it needs, overrides what it cares about and hands it to the consumer by const reference:

const auto settings =
testSettings::make<ConstraintSettings>()
.with(&ConstraintSettings::setShakeMaxIter, 100)
.with(&ConstraintSettings::setShakeTolerance, 1e-8)
.apply([](auto &config) { config.activateShake(); })
.build();
constraints::Constraints constraints(settings);

Consumers keep a reference to the settings they are given, so keep the result of build() in a named variable that outlives the consumer; never pass a temporary.

Values that were not overridden keep the defaults of the default constructor. Settings without a sensible default (for example the water model) throw on access until they are set.
