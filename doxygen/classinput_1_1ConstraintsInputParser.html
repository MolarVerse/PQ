input::ConstraintsInputParser::ConstraintsInputParser ( ConstraintSettings & constraintSettings)
explicit

Construct a new Input File Parser Constraints:: Input File Parser Constraints object.

following keywords are added to the _keywordFuncMap, _keywordRequiredMap and _keywordCountMap: 1) shake "<on/off>" 2) shake-tolerance "<double>" 3) shake-iter "<size_t>" 4) rattle-iter "<size_t>" 5) rattle-tolerance "<double>"

Parameters
constraintSettingsReference to the ConstraintSettings object which will be used to configure the constraints based on the parsed input keywords.
