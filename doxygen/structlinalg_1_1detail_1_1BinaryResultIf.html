template<bool Valid, typename Op, typename L, typename R>
struct linalg::detail::BinaryResultIf< Valid, Op, L, R >

BinaryResult_t<Op, L, R> if Valid, otherwise no type

The return type of an operator template is substituted before its constraints are checked (clang), also for operand pairs the operator is not meant for, e.g. StaticMatrix3x3 * Vec3D. Computing the element type for them recurses endlessly (StaticMatrix3x3 * double asks for the same operator again). The element type is therefore only computed if Valid, the operand concept of the operator.
