std::optional< RigidWaterGeometry > WaterModelSettings::getRigidWaterGeometry ( ) const
nodiscard

Get the rigid geometry parameters for a water model.

Only rigid water variants return geometry data. Flexible water models return std::nullopt and are handled without constraints.

Returns
The O-H and H-H distances for rigid models, or std::nullopt if the model is not rigid.
