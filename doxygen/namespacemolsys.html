enum class molsys::HybridZone : std::uint8_t
strong

Defines the zones for hybrid type calculations.

This enum categorizes molecules based on their distance from the center of mass in hybrid calculations. The zones are assigned concentrically based on radial distance thresholds.

Enumerator
NOT_HYBRID 

Default, molecule not assigned to any hybrid zone

CORE 

Innermost region (distance ≤ core radius)

LAYER 

Inner zone layer region (core radius < distance ≤ layer radius - smoothing thickness)

SMOOTHING 

Transition region between inner and outer region (layer radius - smoothing thickness < distance ≤ layer radius)

POINT_CHARGE 

Point charge region surrounding the inner region (layer radius < distance ≤ layer radius + point charge thickness)

OUTER 

Outer region beyond point charges (distance > layer radius + point charge thickness)
