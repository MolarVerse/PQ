Detailed Description

RAII guard that starts a named timings section on construction and stops it on destruction - including on early return or when unwinding due to an exception.

Intentionally neither copyable nor movable: it represents exactly one active measurement scope tied to the stack frame that created it. Construct it with Timer::scoped(name) and bind it to a local variable, e.g.: 

auto _ = someTimer.scoped("nonCoulomb");
