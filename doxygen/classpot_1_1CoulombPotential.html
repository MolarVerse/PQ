Detailed Description

CoulombPotential is a base class for all coulomb type potentials.

it inherits in general the coulombRadiusCutOff, coulombEnergyCutOff and coulombForceCutOff to all coulomb type potentials

available for:

  • shifted potential
  • wolf summation as long range correction

◆ CoulombPotential()

pot::CoulombPotential::CoulombPotential ( double coulombRadiusCutOff)
explicit

Construct a new Coulomb Potential:: Coulomb Potential object.

the coulomb energy cutoff is set to 1 / coulombRadiusCutOff and the coulomb force cutoff is set to 1 / (coulombRadiusCutOff * coulombRadiusCutOff) the coulomb pre factor is not included here but later in the calculate function of the derived classes
