processes a line of the atom section of the rst file

the line looks like this: atomTypeName randomEntry MolType x y z vx vy vz fx fy fz

Note
for backward compatibility the line can also look like this: atomTypeName randomEntry MolType x y z vx vy vz fx fy fz x_old y_old z_old vx_old vy_old vz_old fx_old fy_old fz_old but the old coordinates, velocities and forces are not used and also not read from the file

processes the atom section of the rst file

this function reads one molecule from the restart file and ends if number of atoms in the molecule is reached. Then the RestartFileReader continues with the next section (possibly the atom section again for the next molecule)

Parameters

engine
