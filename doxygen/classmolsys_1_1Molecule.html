◆ isMMMolecule()

bool molsys::Molecule::isMMMolecule ( ) const
nodiscard

Determines if this molecule should be treated as a MM molecule.

The classification logic is as follows:

  • For MM-only simulations: all molecules are MM molecules
  • For QM-only simulations: no molecules are MM molecules
  • For hybrid QM/MM simulations: active molecules are MM molecules
Returns
true if the molecule should be treated with MM methods, false otherwise

◆ reconstructAtomsAroundCenterOfMass()

void molsys::Molecule::reconstructAtomsAroundCenterOfMass ( const Box & box)

reconstructs atom positions around the current center-of-mass image

Molecules cut by the periodic box carry raw coordinate jumps from the current box. Before a manostat changes the box, these jumps have to be converted back to molecular internal vectors around the cached molecular center of mass, otherwise the old box length leaks into constrained intramolecular distances after the resize.
