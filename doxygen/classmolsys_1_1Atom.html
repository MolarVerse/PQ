bool molsys::Atom::isMMAtom ( ) const
nodiscard

determine if an atom should be treated as MM

Returns
true if the atom should be treated as MM, false otherwise

Checks if an atom qualifies as a MM atom based on:

  • MM-only job types (all atoms are MM)
  • QM-only job types (no atoms are MM)
  • Atom is activated for hybrid calculation
